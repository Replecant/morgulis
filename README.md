# Моргулис: Пепел Эшфорда

Прототип браузерной игры в сеттинге **Моргулис**: самостоятельный вымышленный мир, в котором звезда почти перестала светить и стала тусклой и зеленоватой. Дизельпанк, угасающая цивилизация, готика, промышленность и сверхъестественный ужас. Канон мира — в [LORE.md](LORE.md).

Ваш персонаж — лейтенант — и трое солдат, карательный отряд нефтяного барона Олдриджа — прибывают в деревню Эшфорд, которая перестала платить подать. Расспросите жителей, разберитесь, что происходит на заброшенной красильне, и покончите с «Пастырем».

## Играть онлайн

https://replecant.github.io/morgulis/ — обновляется автоматически при каждом пуше в `main`.

## Запуск локально

Нужен Node.js 18+.

```bash
npm install
npm run dev        # http://localhost:5173
```

Сборка в статические файлы (`dist/`, можно выложить на GitHub Pages):

```bash
npm run build
npm run preview
```

## Управление

**Деревня:** WASD / стрелки или клик мышью — идти; `E` / Пробел — говорить; клик по персонажу — подойти и заговорить.

**Бой:** ЛКМ — выбрать солдата / идти / атаковать; `1–5` — оружие и способности; `Tab` — следующий солдат; `Enter` — конец хода; ПКМ / `Esc` — отмена.

## Что есть

- **Главное меню** в готическом стиле и **книга правил**.
- **Создание персонажа в виде книги «Личное дело»**: имя, пол, возраст, внешность → профессия → характеристики → навыки и таланты → подпись. Созданный персонаж становится командиром отряда в прологе.
- **Ролевая система** — облегчённая d20, см. [RULES.md](RULES.md).

## Механики пролога

- **Диалоги с выбором.** То, что вы узнали у жителей, открывает новые реплики: можно уговорить ополченцев разойтись, получить у священника нюхательную соль против шёпота демонолога, найти обходной путь на фабрику.
- **Пошаговая тактика.** У каждого юнита 2 очка действия (ОД): перемещение = 1 ОД, атака завершает ход. Попадание — бросок d20 против Защиты цели; половинное укрытие даёт цели +3 к Защите, полное — +5; броня поглощает урон.
- **Отряд:** ваш персонаж (оружие и умение зависят от профессии, плюс «Командный клич»), сержант (карабин, граната), стрелок (винтовка, прицельный выстрел), санитар (карабин, перевязка). Здоровье сохраняется между боями.
- **Противники:** крестьянское ополчение (вилы, старые ружья; без вожака разбегаются) и демонолог Мордекай Вейл: зелёное пламя (игнорирует укрытия, бьёт по соседним клеткам), «Шёпот Бездны» (ужас: 1 ОД в следующем ходу), призыв бесов.

## Структура

```
src/
  main.ts      точка входа, ввод, игровой цикл
  rules.ts     ролевая система: черты, навыки, профессии, таланты, формулы
  menu.ts      главное меню, книга правил
  book.ts      компонент книги с перелистыванием
  creation.ts  создание персонажа
  state.ts     состояние игры и флаги сюжета
  data.ts      оружие, отряд, противники, тактические карты
  dialogs.ts   все диалоги (дерево узлов)
  explore.ts   деревня: карта, движение, взаимодействие
  combat.ts    пошаговый бой и ИИ противников
  gfx.ts       процедурная графика: персонажи, небо, свет
  ui.ts        диалоговое окно, HUD, боевая панель
```

Вся графика генерируется кодом, звука нет, внешних ассетов нет. Для отладки откройте игру с `?debug` — в консоли появится `window.morgulis`.
