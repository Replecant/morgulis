# Моргулис: Пепел Эшфорда

Прототип браузерной игры в сеттинге **Моргулис**: мрачный дизельпанк, викторианская Британская империя после катастрофы, готический ужас и вечное тусклое зелёное светило — Око.

Лейтенант Карвер и трое его солдат на службе у нефтяного барона Олдриджа прибывают в деревню Эшфорд, которая перестала платить подать. Расспросите жителей, разберитесь, что происходит на заброшенной красильне, и разберитесь с «Пастырем».

## Запуск

Нужен Node.js 18+.

```bash
npm install
npm run dev        # http://localhost:5173
```

Сборка в статические файлы (`dist/`, можно выложить на GitHub Pages):

```bash
npm run build
npm run preview
```

## Управление

**Деревня:** WASD / стрелки или клик мышью — идти; `E` / Пробел — говорить; клик по персонажу — подойти и заговорить; `M` — звук.

**Бой:** ЛКМ — выбрать солдата / идти / атаковать; `1–5` — оружие и способности; `Tab` — следующий солдат; `Enter` — конец хода; ПКМ / `Esc` — отмена.

## Механики

- **Диалоги с выбором.** То, что вы узнали у жителей, открывает новые реплики: можно уговорить ополченцев разойтись, получить благословение священника, найти обходной путь на фабрику.
- **Пошаговая тактика.** У каждого юнита 2 очка действия (ОД): перемещение = 1 ОД, атака завершает ход. Половинное укрытие даёт −25% к шансу попадания, полное — −40%; на дальней дистанции точность падает.
- **Отряд:** лейтенант (револьвер, сабля, «Командный клич»), сержант (карабин, граната), стрелок (винтовка, прицельный выстрел), санитар (карабин, перевязка). Здоровье сохраняется между боями.
- **Противники:** крестьянское ополчение (вилы, старые ружья; без вожака разбегаются) и демонолог Мордекай Вейл: зелёное пламя (игнорирует укрытия, бьёт по соседним клеткам), «Шёпот Бездны» (ужас: 1 ОД в следующем ходу), призыв бесов.

## Структура

```
src/
  main.ts      точка входа, ввод, игровой цикл
  state.ts     состояние игры и флаги сюжета
  data.ts      оружие, отряд, противники, тактические карты
  dialogs.ts   все диалоги (дерево узлов)
  explore.ts   деревня: карта, движение, взаимодействие
  combat.ts    пошаговый бой и ИИ противников
  gfx.ts       процедурная графика: персонажи, небо, свет
  ui.ts        диалоговое окно, HUD, боевая панель
  sfx.ts       синтезированные звуки (WebAudio)
```

Вся графика и звук генерируются кодом, внешних ассетов нет. Для отладки откройте игру с `?debug` — в консоли появится `window.morgulis`.
