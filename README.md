# Моргулис

Прототип ролевой песочницы в сеттинге **Моргулис** — самостоятельном вымышленном мире, где звезда почти перестала светить и стала тусклой и зеленоватой. Дизельпанк, угасающая цивилизация, готика, промышленность и сверхъестественный ужас. Канон мира — в [LORE.md](LORE.md).

Вы приходите в небольшой регион под властью нефтяного барона Олдриджа — один, без отряда. Серая пустошь, нефтяная деревня Эшфорд, жучиные фермы Ричморда, тракт и железная дорога к форту барона.

## Играть онлайн

https://replecant.github.io/morgulis/ — обновляется автоматически при каждом пуше в `main`.

## Запуск локально

Нужен Node.js 18+.

```bash
npm install
npm run dev        # http://localhost:5173
```

Сборка в статические файлы (`dist/`, можно выложить на GitHub Pages):

```bash
npm run build
npm run preview
```

## Быстрый старт для тестов

- В главном меню — «Быстрый старт»: выберите профессию, и игра начнётся с готовым героем.
- Или откройте игру с параметром `?quick` (солдат) либо `?quick=shooter|saboteur|occultist|technician|medic` — меню пропускается.

## Управление

**Деревня:** WASD / стрелки или клик мышью — идти; `E` / Пробел — говорить; клик по персонажу — подойти и заговорить; `Q` — отряд и лечение; `I` — снаряжение; `C` — лист персонажа; уйти за край деревни — на глобальную карту.

**Бой:** ЛКМ — выбрать солдата / идти / атаковать; `1–5` — оружие и способности; `Tab` — следующий солдат; `Enter` — конец хода; ПКМ / `Esc` — отмена.

## Что есть

- **Главное меню** в готическом стиле и **книга правил**.
- **Создание персонажа в виде книги «Личное дело»**: имя, пол, возраст, внешность → профессия → характеристики → навыки и таланты → подпись. Созданный персонаж — никто: чужак, сошедший с поезда у разъезда Эшфорд.
- **Ролевая система** — облегчённая d20, см. [RULES.md](RULES.md).
- **Ранения и лечение как ресурс**: бинты, медикаменты, пайки; тяжёлые раны лечатся только операцией (окно «Отряд», клавиша `Q`).
- **Шиллинги и торговля**: у каждого торговца свой ассортимент — оружие, броня, патроны, лекарства, спецснаряжение.
- **Снаряжение отряда** (клавиша `I`): «человечек» с 8 слотами — оружие ×2, голова, тело, руки, ноги, оберег, патронташ — и общий обоз; перетаскивание мышью.
- **Боевой кураж 0–3**: штыковая атака, отчаянный рывок, последний натиск, спасение товарища.

## Регион

Глобальная карта в духе Mount & Blade: отряд свободно ходит по карте (клик или WASD, по дороге быстрее), идут дни и часы, раз в сутки отряд съедает паёк. Деревни — входы в локальные сцены; уход за край сцены возвращает на карту.

- **Эшфорд** — нефтяники: качалки, резервуары, разъезд с цистернами, заброшенные дома.
- **Ричморд** — жучиные фермы: скот вымер, разводят жуков-тяжеловозов на мясо и панцирь.
- **Фенмор** — грибные фермы в болотистой низине: грядки, погреба, штольня, светящиеся грибы вместо фонарей. Отходы идут на корм жукам Ричморда.
- **Форт барона** — пока только ворота со стражей.
- **Примечательности** — события с проверками навыков: руины дирижабля, разрушенный пост, старые кости, остов грузовика, газовый факел. На карте их не видно, пока отряд не подойдёт близко; найденные остаются отмеченными (зарево газового факела видно издалека).
- **Старый фронт** к западу от Эшфорда — место сражений между бароном этих земель и соседними: траншеи, проволока, воронки, несколько ржавых бронемашин. Там бродят группы **траншейных мертвецов** (окопный, стрелок, газовый, сапёр в панцире): бой в траншеях, бегство или попытка затаиться; павшие поднимаются снова через двое суток. Находки: старые траншеи, командный блиндаж, ржавая бронемашина.
- **Банда мародёров** бродит по пустоши и преследует отряд: драться, откупиться, запугать или ускользнуть.
- Задания: клапан для Иды (Эшфорд), жучиха Мэг (Ричморд), грибной корм (Фенмор → Ричморд), мародёры у поста.

## Структура

```
src/
  main.ts      точка входа, ввод, игровой цикл
  worldmap.ts  глобальная карта: перемещение, время, места, банда
  explore.ts   локальные сцены деревень: объекты, жители, жуки
  folk.ts      фоновые жители деревень: маршруты и реплики
  rules.ts     ролевая система: черты, навыки, профессии, таланты, формулы
  wounds.ts    ранения, запасы, перевязка, привал, операции
  items.ts     предметы, слоты, стартовое снаряжение, итоговые бонусы
  inventory.ts окно снаряжения
  sheet.ts     лист персонажа
  trade.ts     торговля и ассортимент торговцев
  menu.ts      главное меню, книга правил
  book.ts      компонент книги с перелистыванием
  creation.ts  создание персонажа
  state.ts     состояние игры и флаги сюжета
  data.ts      оружие, отряд, противники, тактические карты
  dialogs.ts   все диалоги (дерево узлов)
  combat.ts    пошаговый бой и ИИ противников
  gfx.ts       стили внешности персонажей (цвета, шляпы, оружие)
  px.ts        пиксельный движок: холст 480×320, свет с растром Байера, контуры
  sprites.ts   пиксельные персонажи 24×32, фигурки для карты, жуки
  pxworld.ts   пиксельные клетки земли, здания и предметы сцен
  ui.ts        диалоговое окно, HUD, боевая панель
```

`tools/` — скрипты, которыми рамки автора (`src/assets/*.webp`) растянуты под окна: повторяющиеся куски вставляются там, где стык незаметен.

Вся графика — пиксель-арт, который генерируется кодом: мир рисуется в низком разрешении (клетка 20 px) и увеличивается ×2 без сглаживания, свет квантуется ступенями с растровым смешиванием, персонажи — спрайты 24×32. Текст интерфейса остаётся чётким поверх пиксельного слоя. Звука нет, внешних ассетов нет. Для отладки откройте игру с `?debug` — в консоли появится `window.morgulis`.
