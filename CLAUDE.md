# Моргулис

Браузерная игра на TypeScript + Vite (`npm run dev`, `npm run build`). Публикуется на GitHub Pages workflow-ом при пуше в `main`: https://replecant.github.io/morgulis/ — в каждом отчёте автору давать эту ссылку.

- Канон мира — в `LORE.md`. Перед любыми правками текстов сверяйтесь с ним: мир не Земля, никаких реальных стран, городов, брендов и исторических событий; жреческой магии нет; новый крупный лор — только по согласованию с автором.
- Сгенерированных звуков в игре нет намеренно (автору они не нравятся) — не добавлять. Музыка — только треки, которые даёт автор (`src/music.ts`, `src/assets/*.mp3`).
- Ролевая система: `RULES.md` (описание адаптации) и `src/rules.ts` (данные и формулы). Бой использует d20 из rules.ts — не возвращать проценты точности в данные оружия.
- Валюта — шиллинги (`G.money`). Каталог предметов и расходников с ценами — `src/items.ts`, торговцы — `src/trade.ts`.
